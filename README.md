Напиши табличные unit-тесты на Go для функции calculateBMI.

ЦЕЛЬ И СЦЕНАРИЙ:
Протестировать функцию calculateBMI: успешный расчет BMI, классификацию категорий, граничные значения (boundaries) и валидацию ошибок.

КОНТЕКСТ И ОГРАНИЧЕНИЯ:
Сигнатура: 
func calculateBMI(weight, height float64) (bmi float64, category string, err error)

Валидация параметров:
- weight: допустимо только > 0 и < 1000
- height: допустимо только > 0 и < 3

Категории (в точности как возвращает код):
- "underweight": BMI < 18.5
- "normal": 18.5 <= BMI < 25.0
- "overweight": 25.0 <= BMI < 30.0
- "obese": BMI >= 30.0

Обработка ошибок в коде:
Функция возвращает динамические ошибки через fmt.Errorf (sentinel-ошибок нет). 
В тестах проверяй наличие ошибки через флаг wantErr (bool), а при wantErr == true дополнительно проверяй, что err != nil и содержит ожидаемый текст или ключевое слово.

Граничные случаи для проверки:
- weight: <= 0 (например, 0, -5), >= 1000 (например, 1000, 1050), валидные границы (например, 0.1, 999.9)
- height: <= 0 (например, 0, -1.75), >= 3 (например, 3.0, 3.2), валидные границы (например, 0.5, 2.9)
- BMI граничные переходы: 18.5, 25.0, 30.0

СТИЛЬ И ТРЕБОВАНИЯ К ТЕСТАМ:
- Язык: Go, использовать ТОЛЬКО стандартный пакет testing (без testify).
- Структура: Table-driven tests со слайсом анонимных структур в цикле t.Run(tt.name, ...).
- Поля тест-кейса: 
    name string
    weight float64
    height float64
    expectedBMI float64
    expectedCategory string
    wantErr bool
    errSubstr string // подстрока для проверки текста ошибки (если wantErr == true)
- Сравнение float64: учитывать погрешность вычислений с плавающей точкой (math.Abs(gotBMI - tt.expectedBMI) > 0.05).
- Паттерн: Arrange-Act-Assert.
